papa - Der Support Coach für werdende Väter

Eine Web-App, die werdende Väter und Partner durch die Schwangerschaft, das Wochenbett und schwierige Zeiten begleitet.

🌟 Features

Dashboard: Personalisierter Fortschritt je nach Phase (Schwangerschaft, Wochenbett, Verlust).

Deep Talk KI: Generiert empathische Gesprächsimpulse basierend auf der aktuellen Woche, dem Geschlecht und Namen des Kindes.

Wochen-Updates: Entwicklung des Babys (Vergleichsgröße, Gewicht) und Tipps für die Partnerin.

Tools: - Kliniktasche-Checkliste

Notfall-Kontakte

To-Do Listen pro Phase

Support: Spezieller Modus für "Stille Geburt / Verlust" mit angepassten Inhalten und sensibler Ansprache.

🛠 Tech Stack

Frontend: React, Tailwind CSS

Backend / Auth: Firebase

AI: Google Gemini API

Icons: Lucide React
